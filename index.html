Política de Privacidade

Veridian — Última atualização: 04 de junho de 2026

1. Quem somos

O aplicativo Veridian é uma ferramenta de gestão de pedidos e clientes destinada a empresas e seus colaboradores. O responsável pelo tratamento dos dados é o operador da conta Veridian da sua organização.

2. Dados que coletamos

O aplicativo coleta e processa as seguintes informações para fins operacionais:

  • Dados de autenticação: endereço de e-mail e tokens de sessão, gerenciados por meio do serviço Auth0.
  • Dados de clientes: nome, CNPJ, organização, e-mail, telefone, estado e cidade, inseridos pelos usuários do app.
  • Dados de colaboradores: nome, e-mail e cargo dos membros da organização.

3. Como usamos os dados

Os dados coletados são usados exclusivamente para:

  • Autenticar e identificar o usuário no sistema.
  • Gerenciar pedidos, clientes e colaboradores da organização.
  • Gerar relatórios e documentos (PDF) de uso interno.

Não vendemos, compartilhamos nem utilizamos os dados para fins publicitários.

4. Armazenamento e segurança

  • Os tokens de autenticação são armazenados de forma segura no dispositivo usando armazenamento criptografado.
  • Os dados operacionais são transmitidos via HTTPS para o servidor em insert text.
  • A autenticação é gerenciada pela plataforma Auth0, que segue padrões internacionais de segurança.

5. Permissões do dispositivo

O aplicativo solicita apenas a permissão de acesso à internet, necessária para comunicação com o servidor. Nenhuma permissão de câmera, localização, microfone ou contatos é solicitada.

6. Retenção de dados

Os dados são mantidos enquanto a conta da organização estiver ativa. O administrador da conta pode solicitar a exclusão de dados a qualquer momento pelo e-mail abaixo.

7. Direitos do usuário (LGPD)

Conforme a Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018), o usuário tem direito a:

  • Acessar, corrigir ou excluir seus dados pessoais.
  • Revogar o consentimento a qualquer momento.
  • Solicitar a portabilidade dos seus dados.
